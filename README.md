# 테트리스 건물 경주 🏗️

테트리스 메커니즘을 응용한 2인 대전 건설 경쟁 게임입니다.

> 🎮 **[지금 바로 플레이하기](#개발-환경)** | 📖 **[배포 가이드 보기](./DEPLOYMENT.md)**

## 게임 설명

두 플레이어가 각자 테트리스를 플레이하면서 건물을 건설하는 경쟁 게임입니다. 줄을 지울 때마다 건물이 쌓이고, 먼저 목표 높이(50)에 도달하는 플레이어가 승리합니다!

### 핵심 메커니즘

1. **줄 제거 = 건물 건설**: 테트리스에서 줄을 지울 때마다 건물 높이가 증가합니다
2. **빈칸 페널티**: 블록 사이에 갇힌 빈칸이 많을수록 건물이 점점 낮아집니다
3. **속도 경쟁**: 상대보다 줄을 지우는 속도가 느리면 건물이 점점 낮아집니다
4. **승리 조건**: 먼저 목표 높이에 도달하거나, 상대가 게임오버 되었을 때 더 높은 건물을 가진 플레이어가 승리

## 조작법

### 플레이어 1 (왼쪽)
- **A/D**: 좌/우 이동
- **W**: 블록 회전
- **S**: 빠르게 낙하
- **Shift**: 즉시 낙하 (하드 드롭)

### 플레이어 2 (오른쪽)
- **←/→**: 좌/우 이동
- **↑**: 블록 회전
- **↓**: 빠르게 낙하
- **Enter**: 즉시 낙하 (하드 드롭)

### 공통
- **스페이스바**: 게임 시작/재시작
- **ESC**: 일시정지

## 게임 화면 구성

```
[플레이어1 테트리스] [플레이어1 건물] [플레이어2 건물] [플레이어2 테트리스]
```

각 플레이어는:
- 왼쪽/오른쪽에 테트리스 게임 보드
- 중앙에 건물 높이를 나타내는 바
- 실시간으로 점수, 지운 줄, 건물 높이, 빈칸 개수 표시

## 게임 전략

1. **빈칸 최소화**: 블록을 깔끔하게 쌓아 빈칸을 만들지 않는 것이 중요합니다
2. **빠른 줄 제거**: 가능한 빨리 줄을 지워야 건물이 감소하지 않습니다
3. **연속 제거**: 한 번에 여러 줄을 지우면 더 많은 높이를 얻습니다
4. **상대 방해**: 상대가 실수하기를 기다리는 것도 전략입니다
